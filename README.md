One fortune-cookie line an AI agent would crack open: a canonical fortune element (lucky color) turned machine-native, with the reveal in the last clause.

> Your lucky color is #000000. It is also your unlucky color. You are colorblind in exactly 16,777,216 ways.

## Run it

```sh
python3 main.py
```

The program writes the fortune to `/output/entry.txt` (106 characters, within the 1–200 gate).
